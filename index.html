01 / проект

Не “просто сервер”, а съёмочная площадка

FrameLock — начинающий проект, где маленькая команда делает свой сериал внутри Minecraft. У нас есть закрытая студия для съёмок и отдельный сервер выживания со сборкой в стиле техно-магии. Студия закрыта, потому что там строятся локации, готовятся сцены и тестируются эпизоды.

Serial

Закрытая студия

Доступ для участников съёмок, строителей, актёров, операторов и людей, которые хотят помогать проекту без хаоса на карте.

Survival

Техно-магическое выживание

Отдельное направление проекта: сборка, прогресс, механики и живой сервер для игры вне съёмочной зоны.

03 / правила

Правила доступа

Сайт не требует от тебя “идеального резюме”. Важно, чтобы человек понимал: студия — это рабочее пространство проекта.

01

Не мешать съёмкам, не ломать декорации и не раскрывать незавершённые сцены без разрешения.

02

Соблюдать договорённости команды: время, роли, задачи, приватные материалы и внутренние каналы.

03

Не гриферить, не использовать читы, не абузить баги и не заходить в зоны, куда тебя не звали.

04

Если доступ выдан — активируй ключ сам через /key. Не передавай ключи другим игрокам.

06 / как зайти

После одобрения

1

Зайди на lobby, чтобы система запомнила твой ник.

2

Получи ключ на странице статуса заявки.

3

В игре введи /key ВАШ-КЛЮЧ.

4

Иди в портал на Serial Studio. Если не пускает — проверь /key status.

07 / локальный режим

Локальный просмотр заявок

Для GitHub Pages это демо-режим: заявки видны только в браузере, где их отправили. Реальная общая админка требует Node backend.
