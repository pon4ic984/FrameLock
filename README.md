# FrameLock GitHub Pages site

Готовая статическая версия сайта FrameLock для GitHub Pages.

## Что внутри

- `index.html` — сайт одной страницей
- `assets/styles.css` — стили
- `assets/app.js` — мобильное меню, форма заявки, проверка статуса в localStorage
- `.nojekyll` — чтобы GitHub Pages отдавал файлы напрямую
- `404.html` — редирект на главную

## Важно

GitHub Pages — статический хостинг. Он не запускает Node.js backend, не хранит серверную базу и не может безопасно держать секретный токен Velocity API.

Поэтому эта версия — готовый публичный сайт/лендинг с формой-заглушкой. Для настоящей автоматической выдачи ключей нужен отдельный backend на Node.js-хостинге или обновлённая связка с API.

## Как выложить

1. Создай репозиторий на GitHub.
2. Загрузи все файлы из этой папки в корень репозитория.
3. Открой `Settings -> Pages`.
4. В `Build and deployment` выбери `Deploy from a branch`.
5. Branch: `main`, folder: `/root`.
6. Сохрани и подожди публикацию.

## Как менять текст

Редактируй `index.html`. Цвета и внешний вид — в `assets/styles.css`.
